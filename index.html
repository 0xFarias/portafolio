Perfil profesional

Soy Jose Luis Farias Valdez, estudiante de Ingeniería de Software en la Universidad Estatal de Milagro (UNEMI), Ecuador. Tengo conocimientos en desarrollo backend, programación estructurada y orientada a objetos, bases de datos y servicios en la nube.

En mis proyectos he construido sistemas web con Python y Django para el área de salud y soluciones de visión por computador: una plataforma que detecta motociclistas sin casco en video y un analizador de enfermedades en mazorcas de cacao.

Funcional Web · Salud

AttentionDoctor: sistema de atención médica

Sistema web para consultorios médicos que reúne en una sola interfaz los pacientes, la historia clínica, la agenda de citas, las atenciones, los servicios y los pagos.

Problema que resuelve
En un consultorio la información suele quedar repartida entre fichas en papel, agendas y hojas de cálculo, lo que complica el seguimiento de cada paciente y la coordinación entre el médico y su asistente.
  • Python
  • Django
  • PostgreSQL
  • Tailwind CSS
  • JavaScript

Funcional IA · Seguridad vial

Tracker IA: motociclistas sin casco

Plataforma web que analiza video en tiempo real, detecta a los motociclistas y verifica si usan casco, registrando cada infracción con su evidencia.

Problema que resuelve
Revisar video manualmente para controlar el uso del casco es lento y deja pasar infracciones; hace falta detectarlas de forma automática y con evidencia verificable.
  • Python
  • Django
  • YOLOv8
  • OpenCV
  • WebSockets
Repositorio

En desarrollo IA · Agrotecnología

CocoaAnalyzer: enfermedades del cacao

Aplicación web que analiza fotografías de mazorcas de cacao y detecta enfermedades con un modelo de visión por computador.

Problema que resuelve
La detección de enfermedades como la moniliasis o la mazorca negra depende de la inspección visual manual; un diagnóstico tardío provoca pérdidas en la cosecha.
  • Python
  • YOLOv11
  • FastAPI
  • Roboflow
  • Google Colab

Implementado Web · Salud hospitalaria

AgendaValoraciones: evoluciones psicológicas

Sistema web donde se agenda en un calendario a los psicólogos de un hospital para que realicen, dentro del mes, la evolución de sus pacientes.

Problema que resuelve
Sin un calendario común es difícil coordinar qué psicólogo valora a cada paciente y cuándo; las evoluciones se atrasan u olvidan y el seguimiento mensual se pierde.
